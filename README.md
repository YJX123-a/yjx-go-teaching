# 围棋教学网站

围棋教学网站，包含28课系统教学、实战演练、双人对弈、人机对弈等功能。
## 网站地址

GitHub Pages: https://yjx123-a.github.io/yjx-go-teaching/
## 功能特性

- **28课系统教学**：从棋盘认识到手筋，覆盖围棋入门到进阶的全部知识点
- **实战演练**：每课配备2-3道互动练习题，在棋盘上直接点击作答
- **双人对弈**：9路棋盘，黑白轮流落子，自动提子，支持悔棋
- **人机对弈**：AI策略（提子>自救>打吃>扩展），可选执黑或执白
- **学习进度**：本地存储学习进度，记录已完成的课程
